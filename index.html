vc4top

Realtime VideoCore IV / V3D telemetry monitor for Raspberry Pi. Signed arm64 Debian package, version 1.0.1.

Install

curl -fsSL https://rughinnit.github.io/vc4top/key.asc \
  | sudo gpg --dearmor -o /usr/share/keyrings/vc4top-archive-keyring.gpg

echo "deb [signed-by=/usr/share/keyrings/vc4top-archive-keyring.gpg] https://rughinnit.github.io/vc4top stable main" \
  | sudo tee /etc/apt/sources.list.d/vc4top.list

sudo apt update
sudo apt install vc4top

Or download the package directly: vc4top_1.0.1_arm64.deb (SHA256).

Run

sudo vc4top          # realtime TUI
sudo vc4top --once   # headless snapshot

vc4top maps /dev/mem, so it must run as root. It is not setuid.

Source and documentation: github.com/rughinnit/vc4top. Install notes: docs/DEBIAN.md.
