vc4infer 1.1.0

Pure-Python API for ONNX inference on the VideoCore IV QPUs. The engine library (libvc4infer.so.1) comes from the vc4infer apt package.

  • vc4infer-1.1.0-py3-none-any.whl

Install

sudo apt install vc4infer
pip install https://rughinnit.github.io/vc4top/pip/vc4infer-1.1.0-py3-none-any.whl
# or as a pip index:
pip install --extra-index-url https://rughinnit.github.io/vc4top/pip/simple/ vc4infer
